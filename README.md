# FinancementsPME.fr

Site éditorial et plateforme de financement dédiée aux dirigeants de PME.

**Site officiel : [https://financementspme.fr](https://financementspme.fr)**

## Le média

Le Média FinancementsPME.fr publie des contenus documentés et pédagogiques sur la finance des PME : trésorerie, BFR, financement bancaire, affacturage, ratios de dette et croissance externe.

Accès direct : [Le Média FinancementsPME.fr](https://financementspme.fr/media/)

## Hébergement

Le site est déployé sur **Vercel** depuis GitHub. Le domaine `financementspme.fr` est géré chez OVH et pointe vers Vercel.

## Structure

- `index.html` — accueil
- `solutions/` — solutions de financement
- `media/` — média et guides
- `contact/` — contact
- `assets/` — ressources graphiques et styles
- `sitemap.xml` — sitemap SEO
- `robots.txt` — directives d'indexation
